# 2026-10-17 工作日志

## 项目：steam-gacha-launcher（通过 Steam 启动国服二游）

- 参考 Better-Endfield 的 Steam 启动思路，用 Go 1.22 开发了一个纯启动器（零注入）CLI 工具。
- 核心能力：游戏客户端定位（注册表 Uninstall/WOW6432Node/HKCU + 常见路径 + 深度≤5 目录搜索）、三种启动模式（direct/launcher/steam）、写入 Steam shortcuts.vdf（备份+去重+appid 生成）、steam:// URI。
- 关键实现细节（已从权威源码还原并单测验证）：
  - shortcuts.vdf 字节格式：值类型 object=0x00/string=0x01/int=0x02；对象以 0x08 结束；字符串以 0x00 结束；int 为 4 字节 LE。
  - appid = crc32(exe+name) | 0x80000000（int32 存入 vdf）；封面长 id = (id<<32)|0x02000000。
  - 参考源：SteamGridDB/steam-rom-manager 的 generate-app-id.ts 与 tirish/steam-shortcut-editor 的 writer.js。
- 内置游戏画像：genshin-cn / hsr-cn / zzz-cn / wuthering-waves-cn / endfield-cn。
- 反作弊立场：只做「兼容」（同 exe/同工作目录/同参数合法拉起），不注入、不绕过。
- 仓库：https://github.com/yss161/steam-gacha-launcher（公开），GitHub Actions 云端编译 Windows amd64/arm64/386。
